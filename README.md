# Traducción de C++ a Python

Tarea de Programación de Computadores: traducción de dos programas de C++ a Python, conservando su lógica.

## Archivos

- `contarNumeros.cpp`: código original que cuenta los números positivos hasta introducir cero.
- `contarNumeros.py`: traducción a Python.
- `registroTienda.cpp`: código original de registro de productos y cálculo de descuentos.
- `registroTienda.py`: traducción a Python.

## Ejecutar

Con Python 3 instalado:

```bash
python contarNumeros.py
python registroTienda.py
```

Los archivos originales en C++ se conservan sin modificaciones.
